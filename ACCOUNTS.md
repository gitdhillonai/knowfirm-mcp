Names and public homes only. No keys, tokens, or passwords belong in this file or in git.

| --- | --- | --- |

| npm package | Published package `@knowfirm/knowfirm-mcp` | https://www.npmjs.com/package/@knowfirm/knowfirm-mcp |

| Publisher | Persoon.ai Inc. (manifest author) | https://knowfirm.com |

Each user brings their own KnowFirm API key from the KnowFirm dashboard. This package does not hold a shared service key.

Routine changes here do not publish a new npm or registry version. A new version needs an owner publish step outside this doc pass.
